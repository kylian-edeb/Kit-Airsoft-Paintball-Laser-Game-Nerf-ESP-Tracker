# Kit-Airsoft-Paintball-Laser-Game-Nerf-ESP-Tracker
Prototype en développement d’un kit modulaire ESP32 de géolocalisation, télémétrie et communication destiné à l’airsoft, au paintball, au laser game et au Nerf. Ce dépôt présente l’avancement technique du projet. Le code n’est actuellement pas distribué sous licence open source.

## Statut du projet

Ce projet est actuellement en cours de développement.

Ce dépôt public sert à présenter :
- l’évolution du prototype ;
- les essais techniques ;
- les choix matériels ;
- les démonstrations fonctionnelles ;
- les étapes de développement.
