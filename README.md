# Kit Airsoft / Paintball / Laser Game / Nerf ESP Tracker

## Présentation

Le **Kit de Détection Tactique** est un projet modulaire basé sur ESP32, conçu pour transformer les parties d’airsoft, de paintball, de laser game et de Nerf en expériences plus stratégiques, connectées et dynamiques.

Le système repose notamment sur :

- des balises mobiles portées par les joueurs ;
- des points de positionnement statiques ;
- un détecteur portable ;
- une communication locale entre modules ESP32 ;
- des fonctions de géolocalisation et de télémétrie.

L’objectif est de permettre aux joueurs de visualiser en temps réel la position des participants encore actifs, selon les règles et les modes de jeu définis par l’organisateur.

## Expérience de jeu

Le projet vise à introduire de nouvelles possibilités :

- gestion avancée des équipes ;
- suivi et reconnaissance sur le terrain ;
- opérations coordonnées ;
- partage de positions ;
- scénarios tactiques évolués ;
- affichage d’informations de télémétrie ;
- meilleure lisibilité de la situation de jeu.

Lorsqu’un joueur est éliminé, sa balise peut cesser d’émettre ou signaler son changement d’état. La réactivation dépend ensuite des règles choisies par l’organisateur :

- retour au point de départ ;
- délai médical ;
- intervention du maître du jeu ;
- utilisation d’un module de réanimation ;
- autre mécanique propre au scénario.

Le fonctionnement repose sur le respect des règles, la confiance entre les participants et la discipline de jeu.

## Technologies étudiées

Le prototype utilise ou explore actuellement :

- ESP32 et ESP32-S3 ;
- ESP-NOW ;
- GNSS/GPS u-blox ;
- LoRa 433 MHz ;
- télémétrie entre balises ;
- points de positionnement fixes ;
- communication radio locale ;
- affichage et suivi des participants.
